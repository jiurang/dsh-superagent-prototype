## 高分设计提炼

最终方案 `00-final` 集中三份设计的强项：

| 来源 | 吸收的特点 |
|---|---|
| 01 Command Center | 常驻项目上下文；项目组合 rail；项目级状态条；需求/任务母版-详情；系统 vs 项目层级；阻塞在列表与详情同时可见 |
| 03 Linear Split | 高密度可扫读主列表；固定详情面板；就地拆任务；状态/优先级/来源的低噪声编码；筛选 chips；键盘操作；动作贴近对象 |
| 04 Kanban Canvas | 列表/看板双视图；需求 4 列 + 任务 6 列；项目泳道；暖纸面 + 卡片层级；任务 inspector；删除确认与撤销 |
| 02 Editorial（备选） | 项目身份带与标题排版；来源原话作为引文块；单一强调色 |

最终不采用 02 的大字号首屏和长卡列表，因为任务效率得分偏低；只吸收它的项目身份与阅读层级。
