# 最终方案 · Project Workspace

> 由 01 Command Center、03 Linear Split、04 Kanban Canvas 三份高分方案合成；02 Editorial 只吸收项目身份与引文排版。

## 一句话

**一个项目、一个镜头、一条主列表、一块常驻详情；需要看全局时切看板，不需要离开项目上下文。**

## 布局

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 项目栏：DEMO ▾  演示项目 · 账单系统  活跃 内部  G:/Projects/...      │
│         4 待确认  2 进行中  1 阻塞  2 记忆待复核     [新建需求]      │
├──────────────────────────────────────────────────────────────────────┤
│ 需求 | 任务 | 收件箱 | 记忆 | 评审        视图：列表 / 看板           │
├───────────────────────────────────────┬──────────────────────────────┤
│ 主列表（约 58%）                      │ 详情面板（约 42%）           │
│ 筛选 chips / 状态分组 / 角色筛选      │ 需求简报 / 任务 / 拆分       │
│ 行：状态点 标题 优先级 来源 任务数    │ 来源原话、验收、任务构成     │
│ 选中行：2px 左侧强调条                │ 尝试、证据、评审、动作       │
└───────────────────────────────────────┴──────────────────────────────┘
```

## 关键特点

1. **项目常驻**：顶部项目栏固定，切项目不离开当前页面；项目短码、名称、根路径、敏感级、状态始终可见。
2. **母版-详情**：需求/任务列表是脊柱，右侧详情独立滚动；不再把表单堆在页面底部。
3. **动作贴近对象**：待确认需求旁直接「确认」；已确认需求旁「拆任务」；任务详情的派发/重试/评审/验收/删除固定底部。
4. **就地拆任务**：拆任务发生在需求详情中，实时预览 N 个任务，逗号不拆、换行才拆。
5. **列表/看板双视图**：默认列表用于高频操作；切看板在当前项目内按状态分列（需求 4 列 / 任务 7 列），跨项目通过项目栏切换。
6. **Attempt 只在详情**：列表只显示当前尝试状态/阶段摘要，不出现 Attempt 表。
7. **系统/项目分层**：项目栏只显示项目级信息；系统设置仍在「设置 → 系统设置」。
8. **视觉语言**：暖纸面 `#f6f4ee`、白色面板、1px 细线、cobalt `#2547e8` 单强调；状态用低饱和语义色；中文正文 12.5–13px。
9. **删除**：详情底部删除，说明软删除语义；看板卡片支持撤销提示。

## 与现有页面的映射

- `XgRequirementsPage` → 项目上下文栏 + 需求主列表 + 需求详情面板 + 新建/拆分抽屉；
- `XgTasksPage` → 项目上下文栏 + 任务主列表 + 任务详情面板；
- `XgProjectsPage` → 项目卡（身份、根路径、统计）+ 系统/项目设置边界；
- `XgInboxPage` / `XgMemoryPage` → 列表 + 常驻详情，转需求 / 确认 / 退回在详情内完成；
- `XgReviewsPage` → 统计 + 决策时间线；
- 其他页面保留业务逻辑，统一使用 `xg-workbench` 视觉语言。
