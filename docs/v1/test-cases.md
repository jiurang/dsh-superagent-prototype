# 验收案例

## A. 设置层级

| ID | 案例 | 预期 |
|---|---|---|
| H1 | 打开「设置」 | 左侧出现「系统设置 · 影响本实例所有项目」和「项目设置 · 只影响所选项目」两个作用域 |
| H2 | 系统设置内切换来源/评估/执行/提示词/部署 | 页面提示“以下配置属于 dsh-superagent 实例，不随单个项目改变” |
| H3 | 进入项目设置 | 可选择项目；显示项目短码、敏感级别、默认优先级、root_path、auto_dispatch、项目 Worker 模型 |
| H4 | 保存项目设置 | 只更新所选项目的 `xg_projects` / `xg_project_settings`，不修改系统设置 |
| H5 | 项目 Worker 模型留空 | 继承系统执行器模型 |
| H6 | 服务商下拉框 | 选项来自 DSH `GET models` catalog，不是自由文本 |

## B. 智能体感知

| ID | 案例 | 预期 |
|---|---|---|
| P1 | 新建「雄大 · 主 Session」并问“有哪些项目/任务” | 调用 `xg.project.list`、`xg.task.list`，回答真实项目名称、短码、ID、根路径 |
| P2 | 主 Session 查概览 | 可调用 `xg.overview` 获取任务状态、收件、待复核记忆和评审数 |
| P3 | Worker Session | 收到任务专属提示，可调用 `xg.task.get/report/artifact.add/triage.record/memory.*` |
| P4 | 查已删除任务 | `xg.task.list` 不返回；`xg.task.get` 返回“任务已删除” |

## C. 任务删除

| ID | 案例 | 预期 |
|---|---|---|
| D1 | 已取消/完成任务详情 | 始终显示「操作 → 删除」 |
| D2 | 删除普通任务 | 列表/统计消失；`deleted_at` 写入；Attempt/证据/审计保留 |
| D3 | 删除活动任务 | 先停止 Ticket，Attempt 置为取消，再隐藏任务 |
| D4 | 删除后查询 | 详情返回“任务已删除”；不能再派发/重试/验收 |
| D5 | v1 数据库升级 | 启动自动增加 `deleted_at`，旧任务可正常删除 |

## D. 本地模式与拆分

| ID | 案例 | 预期 |
|---|---|---|
| L1 | 只配置 local 来源 | setup 通过，账号显示 `local`，不要求 GitHub/gh |
| L2 | 项目 root_path | Worker 直接在项目根目录工作 |
| L3 | 一段话拆任务 | 只有换行拆任务；逗号、分号保留在标题内 |
| L4 | 多行拆任务 | 每行一个任务；提交前显示数量和预览 |

## E. 工作台界面重构

| ID | 案例 | 预期 |
|---|---|---|
| U1 | 打开项目/需求/任务/收件箱/记忆/评审 | 每个页面都有明确的项目上下文或系统入口，不再是纵向堆叠的表单 |
| U2 | 需求页切换状态筛选 | 列表按待确认/已确认/已拆分/已关闭分组；计数与项目栏同步 |
| U3 | 需求页切换「列表 / 看板」 | 看板显示 4 个状态列；卡片保留编号、优先级、来源摘要和任务进度；点击卡片仍打开右侧详情 |
| U4 | 新建需求 | 右侧打开 composer；创建后列表、计数、详情更新，页面不跳到底部表单 |
| U5 | 确认需求并拆任务 | 详情内确认后就地拆分；预览显示任务数；拆完后任务构成立即出现 |
| U6 | 任务页切换「列表 / 看板」 | 看板按任务状态分列；卡片保留 ID、优先级、类型和当前阶段；点击卡片打开详情 |
| U7 | 任务详情 | 顶部显示任务标题、状态、优先级、类型；需求、验收、规格、操作、运行记录、产物、排查、评审、事件按区块排列 |
| U8 | 任务删除 | 详情操作区删除；确认后列表/统计消失，软删除语义仍成立 |
| U9 | 项目页 | 项目身份卡显示短码、名称、状态、敏感级、根路径、创建/更新时间；系统级与项目级边界清楚 |
| U10 | 收件箱 | 列表保留渠道、联系人、原话；详情可转需求；转需求后从未处理列表消失 |
| U11 | 记忆 | 列表 + 详情；草稿/待复核可确认或退回；确认后不再显示操作按钮；无证据产物时保存被阻止并提示 |
| U12 | 评审 | 显示全部/通过/退回统计和决策时间线；空状态说明任务进入评审后才出现记录 |
| U13 | 浏览器控制台 | 上述操作过程中无未捕获异常、无 React 错误 |
| U14 | 从项目卡进入项目设置 | 项目设置页默认选中被点击的项目（`NEW_CENTER_APP`），而不是永远选第一个项目 |
