## P1 · 文档把内部实现端上来

**现象**：`NEW_CENTER_APP-7-A1 / 运行中 / 执行`、`-A2 / 结束 / 评审`、原始 artifact 全文、文件路径、audit 记录直接铺在正文；「暂无描述」「还没有填写验收标准」等空 section 仍占大块空间；标题会滚出视口。

**方案**：

- 标题 + 状态条 sticky，滚动时始终可见；
- 空 section 自动折叠；
- 证据只显示标题、类型、时间、打开入口，正文默认收起；
- Attempt、原始 ID、Ticket、审计记录进「诊断」抽屉。

**验收**：首屏只回答四个问题：现在什么状态、Agent 在做什么、卡在哪、要不要我。

## P2 · 空间与折叠

**现象**：DSH 侧栏没有今天/收件/知识的数量 badge；长文档仍偏窄（工作区最大宽度 850px）。

**方案**：数量 badge 用 DSH 侧栏可用扩展点，或放在页面标题里；文档页允许更宽或全宽。

## P2 · 「旧版」与数据语言

**现象**：顶部常驻「旧版」按钮；主界面仍出现 raw ID、Ticket/Attempt 词汇。

**方案**：旧版入口收进「工作台设置 / 诊断」；主界面只用人话状态，内部词只出现在诊断里。
